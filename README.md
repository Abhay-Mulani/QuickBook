
# QuickBook - Simple Booking UI

QuickBook is a simple booking user interface that allows users to easily select the number of items they want to book, choose additional add-ons for each product, and calculate the final fare based on their selections. It's designed to be intuitive and efficient for booking purposes.

## Features

- **Quantity Selection**: Users can select the number of products they wish to book.
- **Additional Add-ons**: Users can choose from various add-ons for a product (e.g., extra features, customizations).
- **Fare Calculation**: The app dynamically calculates the final fare based on the number of items selected and the add-ons chosen.

## Technologies Used

- **Frontend**: React (for the UI components)
- **Styling**: Tailwind CSS (for responsive and modern design)
- **State Management**: React state hooks for handling user selections

## Installation

1. Clone the repository to your local machine:

   ```bash
   git clone https://github.com/your-username/QuickBook.git
   ```

2. Navigate to the project directory:

   ```bash
   cd QuickBook
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

   Your app should now be running on [http://localhost:3000](http://localhost:3000).

## Usage

- **Step 1**: Select the quantity of the product you want to book.
- **Step 2**: Choose any add-ons you want to include with the product.
- **Step 3**: The final fare will be automatically calculated based on your selections.

## Example

- **Quantity**: 2 products
- **Add-ons**:
  - Add-on 1: $5
  - Add-on 2: $10
- **Final Fare**: (Product price + Add-ons) * Quantity
